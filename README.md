# حولك (Hawlak)

تطبيق ويب يرافق زائر المدينة المنورة بمرشد رقمي من بلده، يتحدث بلغته ولهجته ويفهم صوته. موجّه لكبار السن الذين يصعب عليهم الكتابة. النسخة الحالية تركّز على **منطقة قباء** وبمرشد واحد: **أودين** للإندونيسيين والماليزيين.

> الحالة: نموذج أولي يعمل (MVP). الأماكن حقيقية (الأسماء والمواقع) لكن بلا تقييمات أو أسعار أو ساعات عمل. الوكيل الذكي والصوت لم يُربطا بخدمات حقيقية بعد. راجعي [docs/ROADMAP.md](docs/ROADMAP.md).

## هيكل المشروع

```
hawlak/
├── frontend/            الواجهة (HTML/CSS/JS بدون أدوات بناء)
│   ├── index.html
│   ├── css/             الأنماط: base, screens, characters, layout
│   ├── js/
│   │   ├── data/        الأماكن والمرشدون والبيانات الأساسية
│   │   ├── i18n/        الترجمات وأسطر المرشد الصوتية
│   │   ├── screens/     الشاشات (البداية، الرئيسية، الاستكشاف، المكان، الوكيل...)
│   │   ├── legacy/      ميزات محذوفة من النطاق ولا تُحمَّل (للرجوع إليها فقط)
│   │   └── ...          الحالة، الصوت، الإجراءات، الأحداث
│   └── assets/          صور الشخصيات (أودين صورة ثابتة، والباقي حركة جاهزة للتفعيل)
├── backend/             خادم FastAPI
│   ├── app/main.py      الواجهة البرمجية + تقديم الواجهة
│   └── data/places.json أماكن قباء
├── docs/                نطاق المشروع وخارطة الطريق ومصادر البيانات
└── tests/               اختبار دخان للمسار الأساسي
```

## التشغيل محليًا

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```

ثم افتحي http://127.0.0.1:8000

> **لا تفتحي الموقع من Live Server (المنفذ 5500) في VS Code**: يقدّم الواجهة بدون خادم فلا يعمل الوكيل ولا صوت المرشد (يتكلم بصوت المتصفح الآلي). وإن فتحتِه بالخطأ فالصفحة تحوّلك تلقائيًا إلى المنفذ 8000 إذا كان الخادم شغّالًا.

الاختبار (والخادم يعمل):

```bash
pip install playwright && playwright install chromium
python3 tests/run_smoke.py
```

## الأماكن ونسخة العرض

- الأماكن تُعدَّل في `frontend/js/data/places.js` فقط، ثم `python3 scripts/sync_places.py` يحدّث ملف الخادم.
- لتوليد نسخة العرض الجاهزة للنشر بلا خادم: `python3 scripts/build_prototype.py` (يكتب `dist/prototype.html`).

## المفاتيح

أنشئي ملفًا باسم `.env` في جذر المشروع وضعي فيه مفاتيح الخدمات (`LLM_API_KEY` و`STT_API_KEY` و`TTS_API_KEY`). ملف `.env` مستثنى من git ولا يُرفع.

## النشر (Render)

1. ارفعي المشروع إلى GitHub (الخطوات أدناه)، ثم في render.com: **New + ← Blueprint** واختاري المستودع. يقرأ `render.yaml` تلقائيًا.
2. في صفحة الخدمة ← **Environment** عبّئي: `LLM_API_KEY` و`STT_API_KEY` و`TTS_API_KEY` و`TTS_VOICE` (نفس قيم `.env` المحلي)، و`ADMIN_KEY` إن أردتِ اللوحة.
3. بعد النشر يعمل الرابط `https://hawlak-xxxx.onrender.com`. الخطة المجانية تنام بعد ١٥ دقيقة خمول (أول فتح يتأخر نحو دقيقة، فافتحيه قبل العرض)، وقاعدة الزوار والحجوزات تُمسح عند كل إعادة تشغيل.

## لوحة الفريق (اختيارية)

معطّلة افتراضيًا ولا تؤثر على التطبيق. لتفعيلها ضعي في `.env` سطر `ADMIN_KEY=<كلمة سر قوية>` وأعيدي تشغيل الخادم، ثم افتحي `/admin.html` وأدخلي كلمة السر لترين طلبات الحجز وتغيّري حالتها. غير مربوطة من التطبيق ولا تدخل نسخة العرض.

## ربط المستودع بـ GitHub

المستودع المحلي جاهز وفيه أول commit. أنشئي مستودعًا فارغًا باسم `hawlak` على GitHub (بدون README) ثم نفّذي:

```bash
git remote add origin https://github.com/<اسم-حسابك>/hawlak.git
git push -u origin main
```

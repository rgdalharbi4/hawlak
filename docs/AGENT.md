# الوكيل الذكي («اسأل مرشدك»)

## المبدأ: الإجابات من بياناتنا فقط
الوكيل لا يعرف إلا ما هو مكتوب في `backend/data/places.json` (وسيحل محله ملف الفريق لاحقًا). ما ليس مكتوبًا هناك لا يعرفه، ويقول ذلك.

### كيف نمنع الهلوسة (حواجز في الكود، لا تعتمد على التزام النموذج)
1. **سؤال عن معلومة لا نملكها** (سعر، ساعات، تقييم، رقم هاتف): جواب ثابت من الكود **بدون استدعاء النموذج أصلًا** (`unsupported_topic`).
2. **بيانات المكان فقط في التعليمات**: كل مكان سطر فيه الحقول الموجودة فعلًا، وتعليمات صريحة بعدم التخمين.
3. **فحص كل رد** (`violations`): نرفضه إن فيه ادعاء سعر أو تقييم، أو رقمًا غير موجود في البيانات أو في كلام الزائر، أو ساعات عمل بلا بيانات.
4. **محاولة ثانية** مع تنبيه النموذج إلى المخالفة، ثم **رد آمن** مبني على أسماء الأماكن فقط إن تكررت.
5. **أرقام الأماكن**: أي رقم مكان غير موجود يُحذف، وأي مكان يُذكر اسمه في النص يُضاف إلى بطاقاته.
6. حرارة النموذج منخفضة (0.1) لتقليل الاختراع.
7. **الميزانية:** إن اختار الزائر «اقتصادية» لا يرى النموذج إلا الأماكن المعلَّمة `eco` (والأماكن غير المسموحة تُحذف من الرد). و«مفتوحة» ترى الكل.

حقل `source` في الرد يوضح المصدر: `llm` أو `guard` أو `fallback`.

> حدود: هذه الحواجز تقلّل الهلوسة بقوة لكنها لا تثبت أن كل جملة صحيحة. لذلك نراجع الردود بأنفسنا عبر `tests/run_agent_eval.py` على أسئلة فخ.

## تشغيل مزود حقيقي
في `.env` (جذر المشروع) أضيفي:
```
LLM_PROVIDER=groq        # أو gemini أو anthropic
LLM_API_KEY=...          # مفتاح المزود نفسه
# LLM_MODEL=...          # اختياري، لتغيير النموذج الافتراضي
STT_PROVIDER=groq        # فهم الكلام (Whisper) بالإندونيسية
STT_API_KEY=...
```
بدون `LLM_PROVIDER` تبقى الواجهة على الردود الجاهزة القديمة.

ثم من `backend`:
```bash
python ../tests/run_agent_eval.py     # تجربة حية على ١٣ سؤالًا
python -m pytest ../tests -q          # الاختبارات (لا تحتاج شبكة)
```

## الصوت
- **فهم الكلام:** الواجهة تسجّل بالمايكروفون وترسل إلى `/api/stt` (Groq Whisper، لغة `id`). الضغطة الأولى تبدأ والثانية تُنهي.
- **الرد الصوتي (TTS):** `/api/tts` يدعم `azure` و`google` و`elevenlabs`. كل كلام المرشد بالإندونيسية (الترحيب والأسئلة والردود) يمر عليه إن كان مفعّلًا، وإلا يُنطق بصوت المتصفح. كل جملة تُخزَّن في `backend/cache/tts` فلا نطلبها من المزود مرتين.
  في `.env`: `TTS_PROVIDER` و`TTS_API_KEY`، و`TTS_REGION` لـazure، و`TTS_VOICE` (مطلوب لـelevenlabs، واختياري للباقي: الافتراضي `id-ID-ArdiNeural` في azure وصوت رجالي في google)، و`TTS_RATE=0.9` للسرعة.
  للمقارنة بين المزودين: `python ../tests/run_tts_bakeoff.py` (يحفظ ملفات mp3 في `backend/cache/bakeoff`).
